# Unified Student Lifecycle Management — Next.js Frontend

A Next.js (React) frontend implementing **Data Governance & Data Quality Management (DQM)** for Higher Education Student Lifecycles.

## Features
- **Faculty Grade Entry Portal**: Client-side DQM pre-validation (0.0 - 4.0 bounds) and RBAC restricted submissions.
- **Student 360 & FERPA PII Masking**: Automatic obfuscation of SSN, phone numbers, and addresses for restricted roles.
- **DQM Workbench**: Live tracking across Completeness, Validity, Consistency, and Uniqueness with one-click automated remediation.
- **Compliance Audit Trail**: Forensic activity log viewer.
- **Live Role Switcher**: Interactive simulation of `STUDENT`, `FACULTY`, `REGISTRAR`, and `ADMIN` profiles.

## Getting Started
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
